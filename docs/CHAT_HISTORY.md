## 5. Выбранный кейс

**Геймификация практических заданий AI Sana: рейтинг качества бизнес-задач и открытый выбор команд.**

Цель: создать MVP, который превращает слабое описание бизнес-потребности в подтверждённую карточку, рассчитывает рейтинг готовности и публикует задачу в открытом каталоге. Студенческие команды самостоятельно откликаются, а бизнес вручную принимает решение.

Обязательный сценарий:

1. Ввод черновика.
2. Минимум три уточняющих вопроса.
3. Формирование редактируемой карточки.
4. Рейтинг 0–100 и рекомендации по улучшению.
5. Публикация в общем каталоге.
6. Самостоятельный отклик команды.
7. Ручной выбор или отклонение бизнесом.

Автоматическое назначение команды запрещено. AI не должен придумывать факты или принимать решение за бизнес.

## 6. Принятое решение

Название продукта: **TaskForge AI**.

Выбран лёгкий стек без обязательных сторонних зависимостей:

- HTML, CSS и JavaScript;
- Node.js и встроенный HTTP-сервер;
- OpenAI Responses API со Structured Outputs;
- локальный резервный режим при отсутствии API;
- `localStorage` для демонстрационных данных;
- WebMCP для структурированных действий AI-агентов.

Такой вариант быстро запускается, не зависит от установки пакетов и подходит для стабильной демонстрации.

## 7. Реализованный функционал

- конструктор бизнес-задачи;
- семь AI-вопросов;
- редактируемая карточка со всеми обязательными полями;
- ручное подтверждение перед публикацией;
- прозрачная формула рейтинга и список недостающих сведений;
- уровни: черновик, рабочая, готовая и приоритетная задача;
- каталог с сортировкой и фильтрами;
- пять синтетических задач и пять профилей команд;
- форма отклика с идеей, планом, сроком и ссылкой;
- неограниченное число откликов;
- ручные действия бизнеса: выбрать, отклонить, вернуть на рассмотрение;
- адаптивный интерфейс;
- обработка пустого ввода, ошибок API и некорректного AI-ответа.

## 8. Рейтинг

- контекст и потребность — 20;
- данные и материалы — 20;
- ожидаемый результат — 15;
- критерии успеха — 15;
- ограничения — 10;
- пользователи — 10;
- связь с бизнесом — 10.

Низкий рейтинг не скрывает задачу и не запрещает отклик.

## 9. Проверки

Проверен полный путь:

1. загрузка слабого демо-описания;
2. получение семи вопросов;
3. формирование карточки;
4. рост рейтинга до 100;
5. публикация задачи в верхней части каталога;
6. отправка отклика;
7. ручное принятие отклика бизнесом.

Также проверены JavaScript-синтаксис, резервный AI-режим, WebMCP, отсутствие отслеживаемых файлов с секретами и мобильная ширина 390 пикселей.
