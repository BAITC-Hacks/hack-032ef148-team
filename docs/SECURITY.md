# Безопасность

- API-ключ читается только из `OPENAI_API_KEY` на сервере и не отправляется в браузер.
- Исходные файлы обрабатываются в памяти и не сохраняются в текущей MVP-версии.
- Ограничены размер, количество и допустимые форматы файлов.
- Включены CSP и другие HTTP-заголовки Helmet, сжатие и rate limiting.
- Вызов OpenAI использует `store: false`.
- Решения эксперта и результаты сохраняются в PostgreSQL внутри Docker volume.

Для production необходимо добавить TLS, SSO/OIDC, RBAC, антивирусную проверку, шифрование резервных копий, секрет-хранилище, журнал аудита и утверждённую политику удаления документов.
