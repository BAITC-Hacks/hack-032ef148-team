# Мобильные клиенты

Есть два варианта, оба работают с одним и тем же API.

## 1. Нативное приложение Android и iOS (Expo / React Native)

Код находится в папке [`mobile/`](../mobile). Возможности:
- загрузка документов «до» и «после» с телефона (DOCX, PDF, XLSX, CSV, TXT);
- демо-анализ контрольного комплекта в одно нажатие;
- метрики, фильтры, доказательства с номерами пунктов;
- подтверждение и отклонение выводов с комментарием;
- история анализов и открытие печатного заключения.

### Запуск на телефоне за 2 минуты

1. Установите **Expo Go** из Google Play или App Store.
2. На компьютере запустите сервер (`docker compose up --build` или `npm start`). Телефон и компьютер должны быть в одной Wi-Fi сети.
3. Узнайте локальный IP компьютера: `ipconfig` на Windows, `ifconfig` на macOS/Linux. Например, `192.168.1.100`.
4. Запустите приложение:

   ```bash
   cd mobile
   npm install
   EXPO_PUBLIC_API_URL=http://192.168.1.100:4180 npx expo start
   ```

   В PowerShell: `$env:EXPO_PUBLIC_API_URL="http://192.168.1.100:4180"; npx expo start`
5. Отсканируйте QR-код: камерой на iPhone или из Expo Go на Android.
6. Адрес сервера можно изменить прямо в приложении, в блоке «Сервер».

> Если сервер запущен через `npm start`, в `.env` должно быть `HOST=0.0.0.0`, иначе телефон его не увидит. Docker слушает `0.0.0.0` по умолчанию. Возможно, понадобится разрешить порт 4180 в брандмауэре Windows.

### Без телефона: мобильное приложение в браузере

```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=http://localhost:4180 npx expo start --web
```

Откроется <http://localhost:8081>. Чтобы увидеть экран телефона, включите в браузере режим устройства (F12 → Ctrl+Shift+M).

### Сборка установочных файлов

```bash
npm install -g eas-cli
cd mobile
eas build --platform android --profile preview   # APK для установки напрямую
eas build --platform ios                         # нужен Apple Developer аккаунт
```

## 2. PWA (без установки из магазина)

Веб-интерфейс адаптирован под телефон и устанавливается на главный экран.

- **Android:** откройте адрес в Chrome, затем меню → «Установить приложение».
- **iPhone/iPad:** откройте адрес в Safari, затем «Поделиться» → «На экран „Домой“».
