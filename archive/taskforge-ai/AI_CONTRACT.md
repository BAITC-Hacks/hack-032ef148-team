# AI-контракт TaskForge AI

## Назначение

AI-функция анализирует исходное описание бизнес-задачи и возвращает семь уточняющих вопросов. Она не создаёт факты и не выбирает команду.

## Вход

```json
{
  "industry": "Образование",
  "description": "Мы проводим стажировки, но студенты пропускают сроки подачи заявок."
}
```

## Системная инструкция

```text
Ты анализируешь черновик бизнес-задачи. Верни ровно семь кратких
уточняющих вопросов на русском языке. Вопросы должны заполнить только
пробелы в постановке задачи. Не добавляй и не предполагай факты,
которых нет во входе.
```

## Формат выхода

Сервер запрашивает Structured Output по JSON Schema. Каждый вопрос содержит:

- `key` — одно из разрешённых полей карточки;
- `prompt` — текст вопроса;
- `help` — краткая подсказка для ответа.

```json
{
  "questions": [
    {
      "key": "users",
      "prompt": "Кто столкнулся с этой проблемой?",
      "help": "Укажите конкретную группу пользователей."
    }
  ]
}
```

Разрешённые ключи: `title`, `users`, `data`, `result`, `success`, `constraints`, `contactInteraction`.

## Валидация и ошибки

Сервер отклоняет ответ, если:

- результат не является корректным JSON;
- отсутствует массив `questions`;
- вопросов меньше трёх или больше семи;
- встретился неизвестный ключ;
- `prompt` или `help` не являются строками;
- API вернул ошибку или не ответил за 20 секунд.

При любой из этих ситуаций браузер использует локальный проверенный набор из семи вопросов. Сформированная карточка остаётся редактируемой и требует ручного подтверждения.
