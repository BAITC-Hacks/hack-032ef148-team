# БАТЫС AI: мобильное приложение

Клиент для Android и iOS на Expo SDK 57 (React Native). Работает с тем же API, что и веб-версия.

```bash
npm install
EXPO_PUBLIC_API_URL=http://<IP-компьютера>:4180 npx expo start
```

Отсканируйте QR-код в Expo Go. Подробная инструкция: [docs/MOBILE.md](../docs/MOBILE.md).
